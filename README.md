# Airsoft-World-Express

# Objetivo do site:
- Modelo base do site com as informações das armas do catálogo em estoque para poder ter uma ideia do modelo e funcionamento do site

# Tecnologias utilizadas:
- **HTML, CSS:** Estrutura semântica e layout responsivo.
- **JavaScript:** Interatividade e manipulação do DOM.
- **GitHup:** Hospedagem do repositório.
- **VS Code:** Editor de código.
- **Gemini:** Apoio na geração de trechos de código e revisão.

# Como executar o projeto
- **Baixe os arquivos:** Clique no botão verde **<> Code** no topo desta página e selecione **Download ZIP**.
- **Extraia a pasta:** Descompacte o arquivo baixado no seu computador.
- **Abra o site:** Dê um duplo clique no arquivo `index.html` para abrir o projeto no seu navegador.

# Principais funcionalidades
- **Produtos em estoque:** Exibição do estoque de equipamentos, como armas, coletes e munições e seus respectivos preços.
- **Detalhes do equipamento:** Exibição do alcance, capacidade e bateria da arma e suas modificações e aumentos de preço.

# Requisitos e dependências
- Este projeto foi desenvolvido com tecnologias web nativas e **não possui dependências externas** ou necessidade de instalação de pacotes.
- **Conexão com a internet:** o site apenas precisa de conexão com a internet para carregar esses estilos corretamente
